# solefit-slides
SoleFit social assets (public host for IG/TikTok/Threads/FB ingestion)

- **Carousels** — numbered folders (`01-fit-signs`, `08-meet-solefit`, …), one
  1080×1920 JPG per slide.
- **TikTok slideshows** — [`tiktok/`](tiktok), photo-mode sets (no video),
  one folder of 1080×1920 JPGs plus a caption per set.
- **Instagram Stories** — [`stories/`](stories), story frames with sticker
  zones and posting sequences.
- **Reels** — [`reels/`](reels) — *paused*, kept for reference. Underperformed;
  effort moved to TikTok slideshows and Stories.
- **Pinned posts** — [`pins/`](pins), the Scan / Analyze / Choose device shots
  for the top of the grid, with per-post captions and the pinning order.
