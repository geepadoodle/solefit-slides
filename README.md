# solefit-slides
SoleFit social assets (public host for IG/TikTok/Threads/FB ingestion)

- **Carousels** — numbered folders (`01-fit-signs`, `08-meet-solefit`, …), one
  1080×1920 JPG per slide.
- **Reels** — [`reels/`](reels), one folder per reel with a post-ready
  `reel.mp4`, a `cover.jpg` and a `caption.md`. Rendered from the specs in
  `_tools/` — see [`reels/README.md`](reels/README.md).
